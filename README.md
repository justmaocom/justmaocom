我是 JustMao，軟體工程師。我做過資安研究、Android 與 Flutter，後來轉做後端，現在工作上大多在處理 AI/LLM 平台、RAG 和 Agent。

AI 讓程式寫得更快，但需求有沒有問清楚、修改有沒有弄壞別處、agent 該拿到多少權限，仍然要有人回答。我在 [justmao.com](https://justmao.com) 寫的文章，大多在釐清哪些事可以放心交給 AI，哪些仍要由人把關。
